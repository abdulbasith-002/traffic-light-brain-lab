TRAFFIC LIGHT BRAIN LAB — DETAILED WEBSITE

Included:
- index.html: a responsive, animated educational website with interactive traffic simulator, module explanations, timing table, mini quiz, and selectable Verilog examples.

Open locally:
1. Download and extract the ZIP.
2. Double-click index.html to open it in a modern browser.

Publish for your Website Hosted URL:
GitHub Pages:
1. Create a GitHub repository.
2. Upload index.html to the repository root.
3. Open Settings > Pages.
4. Choose deploy from a branch, branch main, folder /(root), and save.
5. Copy the published URL GitHub displays.

Important:
The Verilog code shown in the website is clearly labeled as educational reference code and may not exactly match your project source files. Check module names, port names, timing parameters, and interfaces before compiling. The project RTL is rule-based unless a separate AI/sensor model supplies vehicle counts. Do not connect this prototype to real traffic signals.
